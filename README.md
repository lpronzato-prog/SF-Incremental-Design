# Space-Filling-Design-and-Kernels-Theory-and-Algorithms
Matlab files for the incremental construction of space-filling designs (following the algorithms in the book [T. Karvonen, L. Pronzato, A. Zhigljavsky: Space-Filling Design and Kernels: Theory and Algorithms, Springer, 2026]), and for the evaluation of various space-filling performance criteria for a given design.
